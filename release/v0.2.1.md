# Enterprise Architecture Composer v0.2.1

This documentation patch makes the first useful result explicit near the top of the README.

## Changed

- Added a copy-paste proof that generates a reviewable architecture report from the committed synthetic manufacturing fixture.
- Linked the live workbench and release-pinned deterministic walkthrough.
- Clarified that the proof demonstrates proposal generation, not production validation or architecture approval.

## Compatibility

The schema, stable IDs, deterministic engine, CLI, fixtures, and handoff contracts are unchanged from v0.2.0. The package remains a source distribution and is not published to npm.

## Verify

Run the [golden quickstart](https://github.com/dkharlanau/enterprise-architecture-composer/blob/v0.2.1/docs/GOLDEN_QUICKSTART.md). The GitHub Release attaches a reproducible npm package tarball, deterministic source archive, and checksums built from the tagged commit.
