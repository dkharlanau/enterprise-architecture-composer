# Enterprise Architecture Composer v0.2.0

The first public executable source release turns explicit business context and constraints into a deterministic, explainable architecture proposal.

## Highlights

- Stable architecture IDs, rule provenance, findings, and human decision separation.
- NFR-aware integration recommendations, scenario comparison, transition planning, and dependency roadmaps.
- Portable bundles and review reports suitable for Git review.
- Explicit Process as Code, Interface as Code, and Visual Workbench handoffs.
- Static GitHub Pages workbench and published JSON schemas.

## Verify

Run the [golden quickstart](../docs/GOLDEN_QUICKSTART.md). The release attaches a reproducible npm package tarball, deterministic source archive, and checksums built from the tagged commit.

## Compatibility and non-goals

This is a `0.x` executable alpha. It does not approve an architecture, replace a repository/CMDB, execute downstream process or interface semantics, or claim compatibility beyond the pinned integration revisions. The package remains private and is not published to npm.
