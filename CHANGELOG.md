# Changelog

All notable public release changes are recorded here. Versions follow Semantic Versioning.

## [0.2.0] - 2026-09-01

### Added

- Deterministic context-to-blueprint composition with stable IDs and explicit rule traces.
- NFR-aware integration decisions, current-to-transition-to-target modeling, option comparison, and dependency roadmaps.
- Portable bundles, review reports, provenance inspection, and explicit Process as Code and Interface as Code handoffs.
- Coordinate-free Visual Workbench projection with pinned compatibility checks.
- Static browser workbench and public schemas on GitHub Pages.

### Boundaries

- This release is an executable alpha, not a universal architecture repository or an architecture approval system.
- Recommendations are proposals. Human adoption decisions remain separate and downstream tools retain their own semantics.
- GitHub Releases provide an installable package tarball and source archive; no npm-registry package is published.
